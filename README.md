⏳ Age Calculator in Python

Welcome to my very first Python project! 🎉

This is a simple, beginner-friendly command-line program that takes a person's age (or birth date) and calculates their exact age broken down into years, months, weeks, days, and hours.

🚀 Features

Multi-Unit Output: Calculates age down to hours!

Fast & Lightweight: Runs entirely in the terminal using pure Python.

Beginner-Friendly Code: Great reference for anyone learning basic Python arithmetic and time handling.

📊 Breakdown Overview

Given an age, the script calculates:

🗓️ Years

📅 Months (~12 months/year)

🗓️ Weeks (~52 weeks/year)

☀️ Days (~365 days/year)

⏰ Hours (~8,760 hours/year)

💻 How to Run

Prerequisites

Make sure you have Python 3 installed on your system. You can check by running:

python --version


Execution

Clone this repository or download the script:

git clone https://github.com/your-username/age-calculator.git
cd age-calculator


Run the script:

python age-calculator.py
